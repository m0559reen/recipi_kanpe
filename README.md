# レシピカンペ（カクテルレシピ帳 PWA）

単一の `index.html`（ビルド不要）＋ Service Worker の PWA です。レシピは端末内の IndexedDB に保存されます。

## ファイル構成

```
index.html              アプリ本体（HTML/CSS/JS すべて入り）
manifest.webmanifest    PWA 定義
sw.js                   オフライン用 Service Worker
icons/                  アイコン 4 種
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成する（例: `recipe-kanpe`）。
2. このフォルダの中身（`index.html` など。フォルダごとではなく **中身**）をリポジトリ直下にアップロードする。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save。
4. 数分後、`https://<ユーザー名>.github.io/recipe-kanpe/` で開けます。

パスはすべて相対指定なので、サブパス公開（`/recipe-kanpe/`）でもそのまま動きます。HTTPS 必須ですが GitHub Pages は標準で HTTPS です。

## スマホに入れる

- iPhone: Safari で開く → 共有 → **ホーム画面に追加**
- Android: Chrome で開く → メニュー → **アプリをインストール**（または「ホーム画面に追加」）

一度開けばオフラインでも使えます。

## データの扱い（重要）

- レシピは **その端末・そのブラウザの中だけ** に保存されます。端末どうしの自動同期はありません。
- 機種変更や端末故障に備えて、画面右上の **設定** にある **バックアップを書き出す** で JSON を定期的に保存してください。**バックアップから復元** で読み込めます。
- iPhone の Safari は、ホーム画面に追加していない状態だと、長期間開かないとデータが消えることがあります。ホーム画面に追加して使うのがおすすめです。

## アプリを更新して再公開するとき

`index.html` を差し替えたら、`sw.js` の先頭近くにある

```js
const CACHE = 'recipe-kanpe-v10';
```

の番号を上げて（今回の版は `v10`、次は `v11`…）からアップロードしてください。古いキャッシュが自動で消えます（保存済みのレシピには影響しません）。

アップロード後、**ページを2回再読み込み**すると新しい版になります（1回目で新しい版を取得し、2回目から表示されます）。

## 使い方メモ

- **量の入力**: `30`（ml）、`1tsp`、`fill`、`1dash`、`1/6` など自由入力。ml と tsp は 5ml = 1マスの目盛りになります。
- **目盛りの色**: 材料の並び順で「濃灰 → 白 → 薄灰 → 白…」と自動で塗り分けます（元の PDF と同じ規則）。
- **材料のアイコン**: 材料ごとの「アイコン」で、飾り（くし切り・円・ドロップ・ツイスト）のほか、fill up を表す「ソーダ」「ジュース」、「エスプレッソ ソロ」「エスプレッソ ドピオ」を選べます。新しく入力した材料には名前と量から候補が入り（例: トニック＋fill → ソーダ、エスプレッソドピオ → ドピオ）、手動で選び直すとそれが優先されます。既存レシピの編集中は自動では変わりません。
- **幅のある量**: 「90-120」のように書くと、最初の数字（90）で目盛りを描き、文字は書いたとおりに表示します。
- **目盛り** のチェックをはずすと文字だけの表示に、**別枠** にすると目盛りの外に小さな1マスで表示します（例: ミントカミカゼの「ミントリキュール 1tsp（沈める）」）。
- **タブでの絞り込み**: 画面上部の横並びタブが **大分類**（ジン・ウォッカ…ノンアルコールの10種。0件でも常に表示）、その左側（狭い画面では上部の帯）が **技法**（中分類）です。大分類ごとに色が決まっていて、一覧のレシピの枠もその色になります。タップして組み合わせて絞り込めます。件数は「今選んでいる組み合わせなら何件ヒットするか」を都度計算して表示します。この2つのタブと検索窓は画面上部に固定されているので、スクロールしても常に操作できます。
- **グラス**: 編集画面の「グラス」で候補（タンブラー・コリンズ・ロックグラス・カクテルグラス・クープグラス・シャンパングラス・ワイングラス・ゴブレット・ショットグラス・マグ・その他）から選びます。「その他」を選ぶとグラス名を自由に入力できます（例: ティキマグ）。選んだグラスの形のアイコンが、一覧でレシピ名の先頭に表示されます。
- **大分類の指定**: 編集画面の「大分類」で選びます。「自動（材料から判定）」のままにすると、最初のスピリッツ（なければリキュール）から判定します。大分類のタブを選んだ状態で追加すると、その大分類が最初から選ばれます。
- **シェイカーのアイコン**: 編集画面の「シェイカーを使う」チェックで表示・非表示を切り替えます。技法で「シェイク」を選ぶと自動でオンになりますが、手動で切り替えるとその内容がそのまま保存され、以後は技法を変えても自動では変わりません。
- **区分タグ / 味わいタグ**: 区分タグはレシピの扱い（メニュー・オリジナル・RinneDex・試作・ホット・卵黄 など）、味わいタグは味の特徴（フルーティ・ドライ など）です。どちらも編集画面で候補から選ぶか、入力して追加します。一覧では名前の下に、区分タグ（塗りつぶし）→ 味わいタグ（枠線）の順で表示されます。
- **絞り込み（補助）**: タブの下に、区分 / 味わい / 副材料・割り材（「すべて含む」「いずれか含む」を切替）の絞り込みがあります。区分と味わいは、同じ段の中では「いずれか」、段どうしは「両方」に一致するものを表示します。検索欄はレシピ名・材料・メモを、ひらがなでも検索できます。
- **表示の切り替え**: 件数の右にある「詳細 / コンパクト」「登録順 / 名前順」で切り替えます（大分類ごとのまとまりは保ったまま並び替えます）。
- **先頭へ戻る**: 画面を下にスクロールすると、左下に「↑ 先頭へ」ボタンが出ます。タップすると画面上部に戻ります。
- **価格**: 編集画面の一番下にある「価格（円）」に入力します。お客さんから見える一覧・印刷には表示されません。
- **印刷 / PDF保存**: 画面右上の「設定」から。タブ・検索・絞り込みの UI は隠れ、レシピ部分だけが出力されます。
