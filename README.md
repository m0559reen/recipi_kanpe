# レシピカンペ（カクテルレシピ帳 PWA）

単一の `index.html`（ビルド不要）＋ Service Worker の PWA です。レシピは端末内の IndexedDB に保存されます。

## ファイル構成

```
index.html              アプリ本体（HTML/CSS/JS すべて入り）
manifest.webmanifest    PWA 定義
sw.js                   オフライン用 Service Worker
icons/                  アイコン 4 種
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成する（例: `recipe-kanpe`）。
2. このフォルダの中身（`index.html` など。フォルダごとではなく **中身**）をリポジトリ直下にアップロードする。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save。
4. 数分後、`https://<ユーザー名>.github.io/recipe-kanpe/` で開けます。

パスはすべて相対指定なので、サブパス公開（`/recipe-kanpe/`）でもそのまま動きます。HTTPS 必須ですが GitHub Pages は標準で HTTPS です。

## スマホに入れる

- iPhone: Safari で開く → 共有 → **ホーム画面に追加**
- Android: Chrome で開く → メニュー → **アプリをインストール**（または「ホーム画面に追加」）

一度開けばオフラインでも使えます。

## データの扱い（重要）

- レシピは **その端末・そのブラウザの中だけ** に保存されます。端末どうしの自動同期はありません。
- 機種変更や端末故障に備えて、メニュー（右上 ⋯）の **バックアップを書き出す** で JSON を定期的に保存してください。**バックアップから復元** で読み込めます。
- iPhone の Safari は、ホーム画面に追加していない状態だと、長期間開かないとデータが消えることがあります。ホーム画面に追加して使うのがおすすめです。

## アプリを更新して再公開するとき

`index.html` を差し替えたら、`sw.js` の先頭近くにある

```js
const CACHE = 'recipe-kanpe-v1';
```

の番号を `v2`, `v3`… と上げてからアップロードしてください。古いキャッシュが自動で消え、次に開いたときに新しい版へ切り替わります（保存済みのレシピには影響しません）。

## 使い方メモ

- **量の入力**: `30`（ml）、`1tsp`、`fill`、`1dash`、`1/6` など自由入力。ml と tsp は 5ml = 1マスでゲージになります。
- **ゲージの色**: 材料の並び順で「濃灰 → 白 → 薄灰 → 白…」と自動で塗り分けます（元の PDF と同じ規則）。
- **ゲージに表示** をはずすと文字だけの表示に、**別枠** にするとゲージの外に小さな1マスで表示します（例: ミントカミカゼの「ミントリキュール 1tsp（沈める）」）。
- **絞り込み**: スピリッツ / 技法 / ★オリジナル / 副材料・割り材（複数選択可、「すべて含む」「いずれか含む」を切替）。検索欄はレシピ名・材料・メモを、ひらがなでも検索できます。
- **印刷 / PDF保存**: メニューから。検索・絞り込みの UI は隠れ、レシピ部分だけが出力されます。
